# Kynetic Spec web UI

This private workspace package contains the SvelteKit web UI bundled with the published `@kynetic-ai/spec` package. It is an internal build input, not a separately published or independently scaffolded application.

Run development and verification commands from the repository root so the shared package, daemon, generated documentation, and web UI stay aligned. See the root [CONTRIBUTING.md](../../CONTRIBUTING.md) for the supported build, test, lint, and formatting commands.

The UI is served by `kspec serve`. Product installation and usage begin in the root [README.md](../../README.md), while operator procedures live in the [Guides](../../docs/guides/index.md).
