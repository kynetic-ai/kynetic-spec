# Guides

The Guides section covers common kspec workflows as step-by-step procedures framed around a goal you want to accomplish. Each guide states its prerequisites, walks through the steps, and ends with a way to verify you succeeded.

- [Starting a New Project](./starting-a-new-project.md) — initialize kspec in a fresh repository
- [Directing Your Agent Effectively](./directing-your-agent.md) — frame requests so your agent does the right thing
- [Importing and Approving a Plan](./importing-a-plan.md) — translate a design document into specs and tasks
- [Authoring and Completing a Task](./authoring-a-task.md) — work through the full task lifecycle
- [Reviewing an Agent's Work](./reviewing-agent-work.md) — evaluate and approve submitted work
- [Upgrading kspec to a New Version](./upgrading.md) — upgrade safely without losing state
- [Recovering From Shadow Branch Issues](./shadow-recovery.md) — diagnose and repair shadow branch problems
